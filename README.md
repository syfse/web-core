# Syfse Web

The Syfse web client is a React application built with Vite and Sass.

## Getting started

```sh
npm install
npm run dev
```

## Project checks

```sh
npm run lint
npm test
npm run build
```

Husky runs ESLint on staged JavaScript/JSX files and the test suite before each
commit. Hooks are installed automatically when dependencies are installed.
